# The Narrative Lens Ltd — GitHub Pages website

Static, responsive one-page website with Home, About Us, The Vision and Contact Us sections.

## Publish using GitHub Pages
1. Create a public GitHub repository (e.g. `thenarrativelens-site`).
2. Upload **the contents of this folder** into the repository root (not the folder itself).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Open the GitHub Pages URL shown in Settings → Pages once deployment finishes.
6. To use `thenarrativelens.ai`, add a custom domain in GitHub Pages, then configure the DNS records GitHub provides in Cloudflare. **Do not delete or replace the Cloudflare MX, SPF, DKIM or SMTP2GO records used for email.**

## Before launch
- Confirm the University of Salford's approved collaboration wording and any logo usage permissions.
- Replace concept-art crops in `assets/` with licensed photographs or bespoke imagery where appropriate; current artwork is derived from an AI-generated homepage concept and may contain baked-in interface elements.
- Test the mobile navigation, all section links and the email CTA on iPhone and desktop.
- The website is static; the contact link opens the visitor's email application and does not require a server.
- Fonts are loaded from Google Fonts; browser fallback fonts are provided.
